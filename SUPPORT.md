# Support

Before asking for help:

1. Run `verity doctor`.
2. Run `verity status --json`.
3. Include the VERITY version, operating system, Python version, and command.
4. Redact credentials, environment secrets, private URLs, and local paths.

Use GitHub Discussions or the issue tracker for:

- Installation and configuration questions.
- Unexpected evidence or guard decisions.
- Verifier behavior.
- Agent integration compatibility.

Use private security reporting for vulnerabilities, not the public issue tracker.
