# Community readiness

VERITY 1.0 provides repository automation for the following trust areas:

| Area | Repository support |
|---|---|
| Security review | CodeQL, dependency review, adversarial, secret, and MCP tests |
| Cross-platform | Windows, macOS, Linux; Python 3.10-3.13 |
| MCP conformance | Protocol, resource, tool, malformed-input, and lifecycle tests |
| Public examples | Python, JavaScript, Docker, monorepo, contradiction, and staleness |
| Signing | Ed25519 key generation, key IDs, SHA-256 integrity, and verification |
| Evidence correctness | Verifier catalog, payload, dependencies, confidence, and trust limits |
| Isolation | Safe environment mode and explicit container mode configuration |
| Team evidence | Organization metadata, audit export, and signed-bundle policy |
| Plugins | Declarative manifest schema and trust levels; no implicit code execution |
| Incident recovery | Database backup, restore, integrity diagnostics, and audit export |
| Onboarding | Templates and copy-paste Quickstarts |
| Governance | Security targets, releases, RFCs, maintainers, and deprecation policy |

External security audits and real-agent sessions remain evidence items that
require third-party reports or recorded test sessions.
